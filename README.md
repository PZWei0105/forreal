# 玩真的 FOR REAL

PZ 的個人遊戲與科技資訊 App：只留玩家真正要的消息，業配、標題黨、攻略農場、課金手遊宣傳一律擋下，並寫明擋下的理由。

- **頭條**：電腦／主機遊戲新聞（遊戲為主、科技 AI 為輔），同一則新聞合併成一張卡，標出「官方」「幾家報導」「傳聞」。
- **特價**：Steam 台灣區特價（只收好評遊戲、記錄觀測以來最低價）、Epic 限時免費。
- **上市**：PC／主機發售日曆、Steam 熱門期待、App Store 台灣付費遊戲榜（買斷制手遊）。
- **科技**：AI、硬體與科技產業消息。
- **濾網**：今天擋掉了哪些、為什麼擋，以及每個來源的狀態。

由 GitHub Actions 每小時更新，GitHub Pages 發布，手機可加到主畫面使用。不需要 API 金鑰、不花錢。
